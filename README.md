# Portafolio de Esteban Muñoz

Desarrollador web frontend. Hago páginas web a la medida para negocios locales de Yotoco, Valle del Cauca, Colombia.

**Ver en vivo:** [estebandev.online](https://estebandev.online)

## Proyectos

| Proyecto | Qué es | Sitio |
|---|---|---|
| Hospedaje Rey de los Vientos | Página para un hospedaje familiar: tarifas por habitación, lugares cercanos y reserva por WhatsApp. | [Ver](https://estebandev.online/proyectos/Hotel-Rey-de-los-Vientos/) |
| Cuchilla Urbana | Página para una barbería: servicios con reserva por WhatsApp, galería de cortes y productos. | [Ver](https://estebandev.online/proyectos/Cuchilla-urbana/) |
| Piamonte Café | Página para un café: menú, ubicación y reserva por WhatsApp. | [Ver](https://estebandev.online/proyectos/Piamonte-Cafe/) |
| Juego de rutas por Yotoco | Recorrido por el pueblo con códigos QR, sellos y álbum de postales. Está en su propio repositorio. | En construcción |

## Tecnologías

- HTML, CSS y JavaScript puro, sin frameworks ni paso de compilación. Lo decidí así a propósito para aprender bien las bases.
- Publicado con GitHub Pages y dominio propio (`CNAME`).

## Estructura

```
index.html        Página principal del portafolio
css/estilos.css   Estilos (los colores están en variables al inicio)
js/               Menú y animaciones al hacer scroll
img/              Imágenes del portafolio
icon/             Ícono de la pestaña
proyectos/        Cada proyecto en su carpeta, con su propio html, css, js e img
CNAME             Dominio estebandev.online (debe quedarse en la raíz)
```

## Verlo en tu computador

No necesita instalar nada. Descarga el repositorio y abre `index.html` en el navegador.

## Cómo trabajo

- `main` es lo que está publicado en el dominio.
- Los cambios nuevos se prueban en la rama `pruebas` y se unen a `main` cuando están listos.
